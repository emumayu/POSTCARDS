# スプレッドシートからサイトの場所データを更新する

シート「POSTCARDS PLACE DATABASE」を編集して、メニューから反映します。
場所データの本体は Supabase の `places` テーブルで、シートが「正」です。シートから消した場所は、サイトからも消えます。

## 1回だけやる準備

1. **Googleの APIキー**を作ります（Places API (New) 用）。
   - Google Cloud Console → プロジェクトを作成 → 「APIとサービス」→「ライブラリ」→ **Places API (New)** を有効化
   - 「認証情報」→「認証情報を作成」→ APIキー。キーの制限で、API を「Places API (New)」だけに絞ります。
   - 請求先の登録が必要です。無料枠の範囲で収まる見込みですが、予算アラートを設定してください。
2. **Netlify の環境変数**を2つ追加します（スコープは Functions、開発用・本番用とも）。
   - `GOOGLE_PLACES_API_KEY` … 上のAPIキー
   - `SYNC_TOKEN` … 16文字以上の、推測されにくい文字列（パスワードのようなもの）
   - 追加したら再デプロイします。
3. **シートの中身を入れ替えます。** `supabase/seed/places-sheet.csv` を、シートに「ファイル → インポート → 現在のシートを置換」で取り込みます（先頭が `キー` の見出しになります）。
4. **スクリプトを入れます。** シートの「拡張機能 → Apps Script」を開き、`docs/sheet-sync/Code.gs` の中身を貼り付けて保存します。シートを開き直すと、メニュー「POSTCARDS」が出ます。
5. メニュー「POSTCARDS → 接続設定」で、開発用・本番用のサイトURLと `SYNC_TOKEN` を入れます。トークンはシートには書かれません。
6. **シートの共有設定を「制限付き」にします**（リンクを知っている人が見られる状態を解除）。

## 場所を追加・更新するとき

1. シートの最後の行に、**店名**だけ入れます（都市は空なら Tokyo になります）。
2. メニュー「**足りない情報を自動入力**」を押します。緯度・経度・公式サイト・Googleマップのリンク・営業状況が入ります。空の欄だけを埋め、手で入れた値は変えません。
   - 「照合した店名」が、探した店と同じか見てください。違うときは、その行の緯度・経度・公式サイト・Googleマップを直します。
   - 見つからない行は、営業状況が `NOT_FOUND` になります。
3. **エリア・ジャンル・タグ・ひとこと・Instagram** を入れます。Instagram は自動では取れないので手入力です（`@アカウント名`）。
4. 準備ができたら、**公開** の列を `公開` にします。空か `非公開` の行は、サイトに出ません。
   - ジャンルが空の行は、`公開` にしても非公開になります。閉店（`CLOSED_PERMANENTLY`）の行も、非公開になります。
5. メニュー「**サイトに反映（開発用）**」で確認し、問題なければ「**サイトに反映（本番）**」を押します。サイトには数分で出ます。

## 列の意味

| 列 | 内容 |
|---|---|
| キー | 行の識別番号。自動で付きます。消さないでください |
| 都市 / 店名 / エリア | 都市は `Tokyo` など。エリアはプラン作成の絞り込みに使われます |
| ジャンル | `hotel` `cafe` `restaurant` `bakery` `shop` `museum` `architecture` `gallery` `walk` |
| タグ | `quiet,design` のようにカンマ区切り |
| 公開 | `公開` のものだけがサイトに出ます |
| 営業状況 / 照合した店名 / PlaceID | 自動入力が書く確認用の列です |
| おすすめの人・時間帯・おすすめ順・あわせて・枠 | 旅程に出る補足（任意） |
| 子供OK / ペットOK | まだサイトでは使っていません（反映もされません） |

## 注意

- シートの行を消すと、次の反映でサイトからも消えます。大量に消えるときは、確認が出ます。
- 先に開発用で試してから、本番に反映してください。
